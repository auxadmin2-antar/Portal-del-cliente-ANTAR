# Checklist de lanzamiento

- [ ] Objetivo/MVP, copy y recursos aprobados; sin placeholders ni claims inventados.
- [ ] Navegación, enlaces, formularios y CTAs funcionan con servicios reales.
- [ ] Móvil, escritorio, teclado, zoom y lector de pantalla representativo revisados.
- [ ] Títulos, descripciones, canonical, imagen social, favicon y 404 correctos.
- [ ] Sitemap solo contiene URLs publicadas; redirects conservan rutas relevantes.
- [ ] Dominio HTTPS y SITE_URL final; Production indexable solo si corresponde.
- [ ] Preview protegido cuando contiene información confidencial.
- [ ] Secrets y proyectos Supabase separados; RLS y permisos negativos probados.
- [ ] Antispam, límites y entregas de formularios comprobados.
- [ ] Rendimiento medido con assets/contenido reales.
- [ ] Analítica y privacidad definidas si se usan; sin rastreadores añadidos por defecto.
- [ ] Backups, retención, restauración y responsables verificados según el servicio contratado.
- [ ] pnpm check y CI satisfactorios; integraciones y callbacks reales comprobados.
- [ ] Release identificada, rollback compatible y autorización de publicación.
- [ ] Smoke posterior en dominio público y revisión de logs.

Anotar fecha, versión, responsable, evidencias y excepciones justificadas.
Esta checklist no se completa automáticamente al compilar la plantilla.
