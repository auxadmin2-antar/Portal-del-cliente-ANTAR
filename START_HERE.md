# Cómo usar esta carpeta

## Para cada website nuevo

1. Duplica esta carpeta con otro nombre, excluyendo node_modules, .next, .vercel
   y cualquier .env. Conserva pnpm-lock.yaml. Crea un repositorio Git propio.
2. Completa docs/product/BRIEF.md con el negocio, audiencia y resultado buscado.
3. Define rutas y contenido en docs/product/SITEMAP_CONTENT.md.
4. Define identidad y referencias en docs/product/DESIGN_BRIEF.md.
5. Define funciones dinámicas en docs/product/FEATURES.md. Si requieren usuarios
   o datos, completa docs/product/DATA_PERMISSIONS.md.
6. Usa docs/templates/TASK.md para pedir una función o página a la IA.
7. Sigue docs/process/WORKFLOW.md hasta el lanzamiento.

Los ejemplos son material de referencia. No inventes clientes, testimonios,
estadísticas, certificaciones, precios o textos legales para rellenarlos.

## Primera instrucción para el agente

Lee AGENTS.md y los documentos de producto. Resume las decisiones que ya están
definidas y señala los datos imprescindibles que faltan. Implementa la tarea
indicada con criterios verificables; conserva componentes y convenciones.
Ejecuta las comprobaciones correspondientes y distingue lo probado de lo pendiente.

No es necesario leer toda la documentación para un cambio de copy. El mapa
de AGENTS.md identifica los documentos pertinentes por tipo de tarea.
